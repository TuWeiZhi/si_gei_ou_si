# 社交平台首图与发布文案

按“漫画全部完成并检查 → 生成并检查首图 → 创建发布文案 Markdown”执行。首图用于图文作品的第一张图片,不承担新增剧情。用户明确限定交付范围时按其要求。

## 首图设计与生图

- **来源**:从实际完成的漫画中选择最能代表故事冲突或情绪的一个场景,重新设计单幅首图,不直接把某张分镜改名交付,也不拼接全套漫画。不在首图揭示结局或补画新情节。
- **比例**:默认 1:1,与漫画图组统一;用户指定首图比例时据此调整。这是本技能的默认值,不视为某个平台的强制规格。未指定平台时不为此停下追问。
- **角色与画风**:逐字复用本次素杯锁定块(含指定换装),保持低饱和扁平彩色环境、黑白素杯本体和浅棕杯套。配角与路人继续按 `character-design.md` 简化。
- **构图**:素杯、关键道具与故事主题在缩小预览时仍清楚。只保留一个视觉焦点,在场景的自然疏处安排标题,保留安全边距,不遮挡五官或关键道具;背景仍延伸到底边,不另开通栏文字底板。
- **文字**:默认 1 个简短中文作品标题,建议不超过 12 字,最多两行;不加分镜编号、大段简介或标签。用户要求无字首图时明确无图内文字。首图标题是独立的展示文案,不套用分镜的无标题约束、对话字数或旁白锚点。

使用内置 `image_gen`,传入定妆照和所选最终分镜的本地绝对路径作为参考;传入前查看尚未查看过的图片。按以下结构展开为实际提示词,不保留占位符:

```text
【用途与画幅】
本次素杯连环画的社交平台首图,单幅插画,非漫画分镜,比例:<实际比例>。
【角色与画风】
<逐字展开本次素杯锁定块,包含视角、透视与指定造型规则>
<沿用本次低饱和扁平彩色环境与手绘线条,展开出场配角的简化描述>
定妆照是素杯外形基准;已完成分镜用于场景、道具和画风参考。
【主题与构图】
<由最终漫画提炼的单一情绪或冲突,具体场景、姿态、道具、视觉焦点与标题位置>
不新增情节,不揭示结局;场景延伸到底边,无分格、边框、分镜编号或水印。
【首图文字】
<只写本次确切标题及其排版;无字首图则明确不添加任何文字>
文字清晰、笔画正确,安全边距充足,不遮挡素杯五官或关键道具,不添加通栏底板。
```

按 `qa-checklist.md` 检查首图,沿用其局部编辑优先、错字降级与每图最多修正 3 次的规则。标题因错字被移除时交付无字首图,在 `publish.md` 记录“首图无文字”,仍提供正常的发布标题。最终首图保存为 `00-cover.png`。

## 发布文案 Markdown

首图完成并检查后,创建同目录的 UTF-8 `publish.md`。依据最终漫画和首图写作,保持本次故事的冷幽默、温暖或心酸等语气。平台与字数要求以用户指定为准;未指定时写通用中文图文文案,不声称已适配未核验的平台限制。

- **发布标题**:给 1 个可直接使用的推荐标题;确有不同表达角度时可附少量备选。标题表达实际主题,不靠夸大、虚构情节或提前公布结局吸引点击。
- **文字描述**:写成可直接复制的短段落,交代情境、情绪和作品看点,不逐张复述整篇漫画。需要收尾时可加一句自然的共鸣或互动句。
- **标签**:默认 4-8 个与角色、题材、情绪相关的 `#标签`,使用本次作品确实涉及的内容,不声称标签是实时热门。
- **图片信息**:记录首图上的实际文字(无字时注明),列出实际文件名和 Markdown 相对链接,首图在前、漫画按编号在后。生成失败或被淘汰的图片不列入上传清单。

以下是文档结构,交付时用实际内容和完整图片清单替换占位说明:

```markdown
# <作品名> · 发布文案

## 发布标题

<可直接复制的推荐标题>

## 文字描述

<可直接复制的发布正文>

## 标签

<本次作品的 #标签,空格分隔>

## 首图文字

<首图实际标题,或“首图无文字”>

## 图片上传顺序

1. [首图](00-cover.png)
2. [第 1 张 · <情节>](01-<情节>.png)
<继续列出所有实际漫画文件>
```
