# 单张生图提示词模板

每张分镜单独生成(后端按 SKILL.md 第 5 步优先级选择:内置 `image_gen` → CLI → Images API 直调),提示词由五个块拼装。【风格块】和【素杯块】全组逐字相同,禁止同义改写。

## 模板结构

```text
【风格块 - 全组固定】
1:1 方形单幅连环画分镜,手绘扁平插画风格。
世界与环境使用低饱和的扁平色块彩色(柔和、克制、不浓艳),
唯独主角素杯保持黑白线稿,它是画面中唯一没有颜色的存在(杯套除外)。
画面简洁,留白充足,只表达一个情节瞬间。
无边框,无分格,无页码,无标题。

【素杯块 - 全组固定】
主角"素杯":一个白色带盖外带纸杯的拟人形象,正常成年人类身高。
杯身即头与躯干,上宽下窄,连盖约占全身高度的三分之二;
杯顶扣一个白色一次性杯盖,盖沿一圈,盖顶微微隆起。
盖沿下方的杯身上段,一对间距略宽的豆点黑眼,其下一条平直短线嘴。
杯身中段偏下套一圈浅棕色瓦楞牛皮纸隔热杯套,竖向瓦楞纹清晰。
两条细长简笔手臂从杯套两侧后方伸出,自然下垂时指尖约到杯底;
杯底下方两条细长简笔腿,约占全身高度的三分之一,赤足。
不穿鞋,除杯套外不佩戴任何配饰。
素杯全身为黑白手绘线稿:白色填充、细黑描线、少量铅笔阴影,
仅杯套是浅棕色,严禁给素杯的杯身、杯盖、手脚、面部上任何其他颜色。
本张嘴部状态:<平直 / 微微下弯 / 微微上弯>

【本张人物块】
<本张出场的重要人物描述:含性别可视特征 + 固定服色/识别物,低饱和彩色>
背景路人(如有):低饱和彩色剪影,无面部五官,无服装细节。
background characters as flat colored silhouettes, no facial features.

【本张画面块】
场景:<在哪,时间氛围,主要环境色>
动作:<谁在做什么,情节瞬间;素杯的肢体语言>
镜头:<远景/中景/特写;素杯在画面中的位置(角落/边缘/中心)>
道具:<关键道具>

【文字块】
画面下方留白处一句手写风格中文旁白:"<≤12 字>"
<如有对话:某角色头顶小气泡:"<≤8 字>",每张最多 1-2 句>
中文文字必须笔画正确、清晰可读。
```

## 负面约束(每张都带上)

```text
不要:给素杯上色、素杯穿鞋或佩戴配饰、素杯丢失杯盖或牛皮纸杯套、多格漫画拼图、分镜边框、
页码、水印、写实照片风、浓艳色彩、复杂背景细节、
大段文字、英文文字、错别字、路人有清晰面部、
任何角色对素杯的外形表示惊讶。
```

**指定造型豁免**:用户任务明确指定素杯的衣物/造型/配饰时:

- 指定物写入【素杯块】,全组逐字复用;默认彩色(低饱和,与整组色系一致),颜色与样式按任务要求
- 负面约束中"素杯穿鞋或佩戴配饰"改写为"素杯穿戴 <指定物> 以外的衣物配饰"
- 负面约束中"给素杯上色"改写为"给素杯的杯身、杯盖、手脚、面部上色",不误伤指定造型的颜色

## 一致性技巧

- 若平台支持以图生图/参考图,从第 2 张起把第 1 张成图作为角色与风格参考传入
- 同一场景连续出现时,场景描述逐字复用(如"同一间开放式办公室,灰绿色工位隔板")
- 环境色跨分镜保持同一套低饱和色系,不换色调
- 文字越短越稳:旁白能砍一个字就砍一个字;错字连续出现两次,该张改为无文字生成,旁白移到交付说明
