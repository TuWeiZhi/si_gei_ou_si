# 单张生图提示词模板

每张分镜直接使用 Codex 内置 `image_gen` 单独生成,提示词由五个块拼装。【风格块】和【素杯块】全组逐字相同,禁止同义改写。

下方模板和“无标题”等分镜文字规则只用于漫画分镜。漫画完成后的社交平台首图按 `social-publishing.md` 组装提示词,沿用角色与画风,另设首图构图和标题。

## 模板结构

```text
【风格块 - 全组固定】
1:1 方形单幅连环画分镜,手绘扁平插画风格。
世界与环境使用低饱和的扁平色块彩色(柔和、克制、不浓艳),
唯独主角素杯保持黑白线稿,它是画面中唯一没有颜色的存在(杯套除外)。
画面简洁,场景自然疏密,只表达一个情节瞬间。
场景背景连续延伸到图片底边,保留正常的地面、墙面或景物;不为文字另开纯色或半透明通栏底条、独立字幕区或留白条。
动作、关键道具和空间关系是视觉重心;非素杯角色以简洁轮廓和色块表达,面部默认平涂,仅在情节必需时加少量点线表情。
无边框,无分格,无页码,无标题。

【素杯块 - 全组固定】
<逐字插入 character-design.md 中完整的素杯锁定描述块,包括视角与透视规则;有指定造型时插入按换装规则调整后的任务锁定块。生成时必须展开为正文,不能只保留文件名或占位说明。>
以传入的素杯定妆照为角色外形基准,保持其五官、杯套、手臂起点、外撇脚掌和整体比例;姿态、指定造型及其自然遮挡按本张画面执行。

【本张人物块】
<本张出场的重要人物描述:含性别可视特征 + 固定发型/服色/识别物,低饱和扁平色块;面部按 character-design.md 简化,情节需要时仅加少量点线表情>
重要人物不画完整精细五官、睫毛、虹膜、精细鼻唇、腮红、皮肤明暗塑形或逐根发丝。
背景路人(如有):低饱和彩色剪影,无面部五官,无服装细节。
background characters as flat colored silhouettes, no facial features.

【本张画面块】
本张嘴部状态:<平直 / 微微下弯 / 微微上弯>
场景:<在哪,时间氛围,主要环境色>
动作:<谁在做什么,情节瞬间;素杯的肢体语言>
镜头:<远景/中景/特写;素杯在画面中的位置(角落/边缘/中心)>
道具:<关键道具>

【文字块】
<按分镜表,从下方“文字选择与排版”中只插入本张适用的文字指令,展开实际文案、说话者及所需的全组旁白排版块。无文字时明确写“本张无图内文字”,不保留未选模式、占位说明或示例文案。>
中文文字(如有)必须笔画正确、清晰可读;只生成本张明确列出的文字。
```

## 文字选择与排版

画面已经讲清的内容无需配文;需要角色说话时优先用对话气泡,已由对话表达的含义不再加旁白。只补无法用画面或自然对话交代的必要信息。

按本张实际需要展开:

- **无文字**:`本张无图内文字,不添加旁白、配文或对话气泡。`
- **对话**:`<说话者> 的对话气泡:“<≤8 字>”。`每张最多 1-2 句,气泡放在说话者附近,尾巴明确指向说话者;全组气泡与字体风格一致,不遮挡脸部和关键动作。不附加重复含义的底部配文
- **必要旁白**:`图内旁白:“<≤12 字>”,直接叠加在场景上。`随后逐字插入本组锁定的旁白排版块;同张确需对话和旁白时,仅保留各自不可替代的信息

有旁白时,生成前锁定全组的锚点、字号、字重、颜色、描边与阴影,逐张复用。用户未指定时使用以下默认排版块:

```text
旁白统一位于画面下方居中,文字基线距底边约为画面高度的10%,保留一致的安全边距。
使用加粗手写中文、白色字面、清楚的深灰描边与轻微阴影,字号、字重、颜色和效果全组一致。
文字直接叠加在完整场景上,文字后方仍保留场景内容,不添加整块文字底板或任何通栏底条。
即使文字处有景物,也靠字重、描边与阴影提高可读性,不为了寻找空白处移到画面顶部、侧边或其他角落。
只有遮挡脸部、关键动作或道具时,才在同一下方区域内轻微调整;优先缩短文字或调整换行,全组位置仍大致一致。
```

## 负面约束(每张都带上)

结构约束仅针对本张镜头下应当可见的部分。特写不要求全身入镜,背面不要求显示五官,衣物或道具遮挡不算结构丢失;比例是底层身体比例,不是透视缩短后的画面测量值。

```text
不要:给素杯杯身/杯盖/手脚/面部上色、素杯穿鞋或佩戴配饰、素杯丢失杯盖或牛皮纸杯套、
素杯手掌无手指或手指模糊、素杯脚掌有脚趾分节、正面站姿脚掌画成竖直椭圆、素杯手臂位置错误(必须从杯套上缘附近的杯身两侧伸出)、
素杯整体比例失调(杯身含盖必须约占全身高度的三分之二/腿部必须约占全身高度的三分之一)、
多格漫画拼图、分镜边框、页码、水印、写实照片风、浓艳色彩、复杂背景细节、
为配文新增纯色或半透明底条、独立字幕区、留白条或整块文字底板,为了寻找空白处让旁白跨分镜满屏换位,
无文字分镜擅自加字、把对话改成底部旁白、用旁白重复气泡已表达的含义,
大段文字、英文文字、错别字、重要配角有精细完整五官或肖像式面部刻画、路人有清晰面部、
任何角色对素杯的外形表示惊讶。
```

**指定造型豁免**:用户任务明确指定素杯的衣物/造型/配饰时:

- 按 `character-design.md` 的换装规则生成任务锁定块,替换其中“不穿鞋、无配饰”等冲突句子,再写入指定物;全组逐字复用,指定物默认低饱和彩色,颜色与样式按任务要求
- 将【风格块】的“唯一没有颜色的存在(杯套除外)”改为“本体保持黑白,杯套与指定衣物配饰可以有颜色”;同步修改锁定块中的绝对配色描述
- 负面约束中"素杯穿鞋或佩戴配饰"改写为"素杯穿戴 <指定物> 以外的衣物配饰"
- 负面约束中"给素杯上色"改写为"给素杯的杯身、杯盖、手脚、面部上色",不误伤指定造型的颜色
- 杯盖、杯套、手脚等结构的可见性按指定衣物和构图判断,不要求穿透衣物显示,不把自然遮挡列为禁止事项

## 一致性技巧

- 按 `../SKILL.md` 的“角色定妆照”规则,从第 1 张起传入定妆照作为角色参考;从第 2 张起可追加第 1 张成图作为风格与场景参考,不能取代定妆照的外形基准
- 若参考成图中的配角面部过细,只沿用其发型轮廓、服色、道具与场景关系,按人物规则重新简化面部,不继承该偏差
- 若参考成图出现配文底条、旁白位置漂移或重复文字,不继承这些偏差;恢复延伸到底边的场景,按本组排版块和本张文字模式生成
- 同一场景连续出现时,场景描述逐字复用(如"同一间开放式办公室,灰绿色工位隔板")
- 环境色跨分镜保持同一套低饱和色系,不换色调
- 保持必要文案简短,不补无必要的文字;错字按 QA 先局部修正,连续两次仍错则移除图内文字,仅将原文与必要的说话者信息移到交付说明
