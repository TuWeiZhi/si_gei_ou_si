# QA 检查清单

每张图生成后逐项检查;不合格项按对应策略处理。

素杯一致性与人物简化规则也用于首图;分镜表、相邻分镜衔接和分镜文字模式只检查漫画分镜。首图与发布文档的追加检查见末尾。

只检查当前镜头、姿态和遮挡条件下应当可见的内容。特写不要求露出脚掌或全身,背面不检查五官,远侧手臂是否可见取决于动作。衣物和道具可自然遮挡杯盖、杯套及身体;被遮挡或裁出画面的项目记为“不适用”,不判为缺失。身体比例结合透视判断,不机械测量画面中的长度。

## 素杯一致性(最高优先级)

- [ ] **素杯本体没有被上色**:杯身、杯盖、手脚、面部为黑白线稿;颜色仅允许浅棕杯套和用户指定的造型物
- [ ] 杯盖、杯套齐全;杯套位置正确(杯身中段偏下,竖向瓦楞纹)
- [ ] 默认不穿鞋、无杯套以外的配饰;用户指定造型时改按任务设定检查,不沿用默认禁令,应当可见的指定物齐全、颜色一致、跨分镜无漂移
- [ ] 细小豆点眼 + 短于眼距的短线嘴,五官集中且周围留白充足;嘴部状态与分镜表一致,没有多余表情符号(眉毛/腮红/汗滴)
- [ ] 手臂从杯套上缘附近的杯身两侧伸出,手掌自然下垂时约到杯底,手指为清楚的简化线条
- [ ] 正面站姿下脚掌扁平圆钝、分别向左右外侧伸展,无脚趾分节;其他姿态遵循透视
- [ ] 身高比例正常(与人类角色等高,杯身连盖约占全身三分之二),不是桌上的小杯子
- [ ] 每张均与角色定妆照比对外形,并与第 1 张比对风格和连续性;定妆照是外形基准,不沿用第 1 张的外形偏差

**不合格 → 按下方统一迭代规则修正。局部着色或外形瑕疵优先编辑,整体比例或多处外形偏差再强化对应描述并重生成。**

## 人物与叙事

- [ ] 重要人物性别一眼可辨,识别物/服色与设定一致
- [ ] 重要配角面部为平涂色面,仅在情节必需时有少量点线表情;没有精细虹膜、睫毛、鼻唇、腮红、皮肤明暗塑形或逐根发丝
- [ ] 路人是无面部的彩色剪影,没有抢戏细节
- [ ] 视觉重心落在本张的动作、关键道具、人物关系和空间关系;没有无叙事必要的配角大脸特写
- [ ] 没有角色对素杯的外形表示惊讶
- [ ] 画面与分镜表的"谁/在哪/做什么"一致;一张图只有一个情节瞬间
- [ ] 与相邻分镜衔接合理(场景、道具、方向感不突兀);镜头景别符合分镜表

**不合格 → 局部道具或人物细节优先编辑;情节、构图或空间关系整体有误时,用更具体的动作和空间描述调整画面块后重生成。**

配角面部过细时,先局部删减五官、皮肤明暗与发丝,保留发型轮廓和服色;若整张已偏向肖像插画,再调整构图与风格重生成。

## 漫画画面与文字

- [ ] 环境色低饱和、克制,素杯的"白"衬得出来;画面不吵不满
- [ ] 无分格、边框、页码、标题、水印
- [ ] 场景背景连续延伸到图片底边;没有为配文另开的纯色或半透明底条、独立字幕区、留白条或整块文字底板
- [ ] 图内文字与分镜表的实际模式一致;无文字分镜没有被擅自加字,画面或对话已讲清的含义没有再用旁白重复
- [ ] 对话气泡对应正确的说话者,尾巴指向明确,没有遮挡脸部或关键动作;能用自然对话表达的内容没有被改成底部配文
- [ ] 有旁白时,位置保持在全组同一下方区域,字号、字重、颜色、描边与阴影一致;有景物的区域也清晰可读,没有为找空白处满屏换位或遮住关键叙事信息
- [ ] 图内中文旁白/对话(如有)**零错字**;笔画清晰可读
- [ ] 无英文乱入
- [ ] 风格与其他分镜一致(色系、线条密度、场景疏密和文字样式)

**文字与背景修正:重复或多余配文先移除;配文底条先编辑恢复原场景,让背景延伸到底边;旁白位置或可读性问题先恢复锁定锚点和字样,不改成底条或移去远处空白。**

**错字处理:先局部修字,必要时缩短文字;同一张连续两次仍有错字时,优先编辑移除图内文字,仅将原文与必要的说话者信息移到交付说明并标注。移除失败再生成无文字版本,不交付带错字的成图。**

## 迭代规则

- 局部问题(错字、多余文字、配文底条、文字位置或字样、局部颜色或道具瑕疵)优先使用内置 `image_gen` 编辑,保留已正确的角色与构图
- 整体偏差(情节、构图、比例或多处结构错误),或局部编辑未能解决的问题,再调整对应提示词并重生成;不机械重复原提示词
- 每张初次生成后最多修正 3 次,局部编辑和整张重生成合并计数;文字降级也计入额度,需为移除错字预留一次。达到上限仍不理想时保留最佳版本并标注问题;没有无错字版本的图片不列为最终成图
- 全组完成后做最终横向检查:所有图并排看一遍,确认素杯认得出、故事读得通、色调统一;有旁白的图位置与字样稳定,每张背景都自然延伸到底边

## 社交平台首图与发布文档

- [ ] 首图在漫画全部完成并检查后另行生成,只有 1 张,不占漫画张数,没有分镜编号或多格拼图
- [ ] 首图沿用本次角色造型、低饱和色系和手绘风格,主题来自实际漫画;没有新增情节或提前揭示结局
- [ ] 首图缩小预览时仍能看清素杯和主题;标题(如有)简短、无错字、不遮挡脸部和关键道具。允许作品标题,不套用漫画“无标题”规则;错字仍按上述处理与修正次数上限执行
- [ ] `publish.md` 在首图完成并检查后创建,标题、正文、标签均为本次作品的实际文案,没有模板占位符或未画出的情节;记录的首图文字与最终图片一致
- [ ] 首图、漫画、文档保存在同一故事目录,文档图片链接可用,上传顺序为 `00-cover.png` → 按编号排列的漫画;交付分别计数并提供文档链接
