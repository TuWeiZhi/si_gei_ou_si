# QA 检查清单

每张图生成后逐项检查;不合格项按对应策略处理。

## 素杯一致性(最高优先级)

- [ ] **素杯没有被上色**:杯身、手脚、面部为黑白线稿,唯一颜色是浅棕杯套
- [ ] 杯套存在且位置正确(杯身中段)
- [ ] 豆点眼 + 短线嘴,嘴部状态与分镜表一致;没有多余表情符号(眉毛/腮红/汗滴)
- [ ] 身高比例正常(与人类角色等高),不是桌上的小杯子
- [ ] 与第 1 张并排比对,无外形漂移

**不合格 → 逐字重用原提示词重生成;"素杯被上色"连续两次,在提示词中把禁令移到开头加粗重试。**

## 人物与叙事

- [ ] 重要人物性别一眼可辨,识别物/服色与设定一致
- [ ] 路人是无面部的彩色剪影,没有抢戏细节
- [ ] 没有角色对素杯的外形表示惊讶
- [ ] 画面与分镜表的"谁/在哪/做什么"一致;一张图只有一个情节瞬间
- [ ] 与相邻分镜衔接合理(场景、道具、方向感不突兀);镜头景别符合分镜表

**不合格 → 修改画面块措辞(更具体的动作动词、更明确的空间关系)后重生成。**

## 画面与文字

- [ ] 环境色低饱和、克制,素杯的"白"衬得出来;画面不吵不满
- [ ] 无分格、边框、页码、标题、水印
- [ ] 图内中文旁白/对话**零错字**;笔画清晰可读
- [ ] 无英文乱入
- [ ] 风格与其他分镜一致(色系、线条密度、留白程度)

**错字处理:缩短文字后重生成;同一张连续两次错字 → 该张改为无文字生成,旁白移到交付说明并标注。**

## 迭代规则

- 每张最多重生成 3 次;仍不理想则保留最佳版本并在交付时标注"建议手动重试"
- 单点小问题(多余文字、局部瑕疵)优先用图像编辑局部修改,不整张重生成
- 全组完成后做最终横向检查:所有图并排看一遍,确认素杯认得出、故事读得通、色调统一
