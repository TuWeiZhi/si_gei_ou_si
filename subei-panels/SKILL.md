# 素杯连环画 Subei Panels

## 核心定位

把一段文字描述的故事,变成一组(默认 4-8 张)1:1 方形、独立单张、按序号阅读的连环画分镜图。

固定视觉 IP 是**素杯**:一个正常人类身高的拟人白色带盖外带纸杯,冷面、安静、容易被忽略的职场小透明。核心视觉反讽:**整个世界是彩色的,唯独素杯是黑白的**——全世界都有颜色,只有它没有。

核心是叙事连续性:素杯贯穿所有分镜,场景与道具前后衔接,每张图配一句极短中文旁白,读者顺着图和旁白就能读完故事。

主角固定为素杯。本技能支持素杯换装,不提供主角替换流程。

## 工作流

### 1. 消化故事

读用户给的故事文字。提炼:

- 起因、经过、转折、结局各是什么
- 出场人物:主角素杯、重要配角、路人
- 关键场景和关键道具
- 故事的情绪基调(冷幽默 / 温暖 / 心酸 / 平静...)

### 2. 按需补全故事

仅在缺失信息会实质改变画面且无法合理补全时提问。故事已足够具体时直接输出分镜表。规则:

- 将必要问题集中一次提出,不设最低题数,不为凑数追问
- 只问影响画面的问题。优先级从高到低:
  1. 含糊的关键情节:转折怎么发生的?结局停在什么画面?
  2. 场景设定:办公室/家里/街头?白天/夜晚?(素杯的世界默认是现代日常)
  3. 重要配角:有几个?各自和素杯什么关系?
  4. 期望张数(默认 4-8 张)
- 每个问题附上你的默认建议,用户不回答某项时按建议执行
- **不要过度追问**。补全目标是"每张分镜有具体可画的内容",不是把故事写成小说。用户已说清楚的不重复问

用户回答后如仍有小缺口,自行合理补全,不再二次提问。

用户已明确要求直接生成或自行决定细节时,按合理默认值补全,简述关键假设后连贯执行;不再为可自行决定的细节停下。

### 3. 角色设定表

输出简短角色设定表(规则见 `references/character-design.md`):

- **素杯**:默认直接使用锁定描述块;用户指定衣物/造型/配饰时,按 `references/character-design.md` 的换装规则生成本次任务的锁定块,替换冲突描述后全组复用
- **重要人物**:每人一句外形描述,**必须含可视化性别特征**(发型、衣着、体态,不靠文字标签),各配一个固定服色或识别物
- **路人**:统一为彩色剪影,无面部细节,融入背景

### 4. 输出分镜表

用表格输出分镜,每张写清楚:序号与情节阶段(起/承/转/合)、画面内容(谁/在哪/做什么/道具)、镜头(远/中/特写)、情绪、图内旁白(≤12 字)或对话(≤8 字/句)。

一张分镜只画一个情节瞬间。默认 4-8 张;极短故事 3 张起,不轻易超过 10 张。

默认输出分镜表后等待用户确认或修改,确认后开始生图。用户已明确授权直接生成、无需确认时,输出简短分镜安排后继续生图,不重复请求确认。

### 5. 逐张生成

本技能面向 Codex 付费用户,直接使用内置 `image_gen` 生成和编辑图片。每张单独生成,不拼格、不带边框。

不使用 CLI、独立 Images API 或自定义中转,不要求用户配置 API 密钥。若当前会话没有提供内置 `image_gen`,说明工具不可用并暂停生图。

每张提示词必须包含(模板见 `references/prompt-template.md`):

- 统一风格块(全组逐字相同):1:1、低饱和扁平彩色世界
- 素杯锁定描述块(全组逐字相同),并强调**素杯全身黑白线稿+浅棕杯套,禁止本体上色**
- 本张出场的重要人物描述
- 本张场景、动作、镜头
- 路人写明"彩色剪影,无面部"
- 图内文字:下方留白处一句 ≤12 字手写风中文旁白;对话气泡每张最多 1-2 句

### 6. 检查与迭代

按 `references/qa-checklist.md` 只检查本张应当可见的内容。以下问题优先修正;局部问题先编辑,整体偏差再调整提示词重生成:

- **素杯本体被上色**(杯身/杯盖/手脚/面部,最高优先级)或外形漂移(杯盖或杯套丢失、嘴眼变形、身高比例变了、多出未指定的鞋子或配饰)
- 人物性别看不出或画反;路人有清晰面部
- 中文错字(零容忍:先局部修字,必要时缩短文字;连续两次仍错则移除图内文字,改图外配文并标注)
- 画面与分镜表情节不符;一张图塞了多个情节
- 环境颜色过艳过吵,压住了素杯的存在感

### 7. 保存交付

最终图保存到 workspace 的:

```text
assets/subei-panels/<故事名>/
```

按顺序命名:`01-<情节>.png`、`02-<情节>.png`...

交付时报告:生成了几张、每张对应的情节与旁白、保存路径、哪些张最稳、哪些建议重生成。

## 输出口径

提问和分镜表要短而准,用表格或紧凑列表。不长篇解释风格理论,让图自己说话。
